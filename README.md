# Library Management System

A Django-based Library Management System that allows users to manage library records with CRUD (Create, Read, Update, Delete) operations through a clean web interface.

## Features

* Add new books
* View all library records
* Update existing book details
* Delete books
* Responsive interface using HTML and CSS
* SQLite database integration

## Technologies Used

* Python
* Django
* HTML
* CSS
* SQLite
* Git & GitHub

## Installation

1. Clone the repository

```bash
git clone https://github.com/bindushree196/Library-Management-System.git
```

2. Navigate to the project

```bash
cd Library-Management-System
```

3. Create a virtual environment

```bash
python -m venv LMS
```

4. Activate it

**Windows**

```bash
LMS\Scripts\activate
```

5. Install dependencies

```bash
pip install -r requirements.txt
```

6. Run the server

```bash
python manage.py runserver
```

7. Open your browser

```
http://127.0.0.1:8000/
```
